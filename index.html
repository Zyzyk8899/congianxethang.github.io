1.1 Khái niệm ngôn ngữ C
UTT p.12

Ngôn ngữ C là ngôn ngữ lập trình bậc trung, có tốc độ thực thi nhanh, khả năng kiểm soát bộ nhớ mạnh mẽ và được dùng nhiều trong hệ thống, phần mềm nhúng, và ứng dụng hiệu năng cao.

C là ngôn ngữ có cú pháp gọn, ít ẩn dụ hơn so với các ngôn ngữ hiện đại, nhưng lại cực kỳ mạnh vì cho phép lập trình ở mức thấp mà vẫn kiểm soát cấu trúc dữ liệu rõ ràng.

Điểm cốt lõi

  • ✓Ngôn ngữ C có tính cấu trúc, hướng thủ tục.
  • ✓Khả năng quản lý bộ nhớ trực tiếp bằng con trỏ.
  • ✓Phổ biến trong hệ thống, nhúng, driver, và engine game.
Ví dụ main.c 
#include <stdio.h>

int main() {
    printf("Xin chao C!");
    return 0;
}
2.1 Kiểu số nguyên và thực
UTT p.24

Trong C, các kiểu dữ liệu cơ bản bao gồm int, float, double, char, cùng với các kiểu unsigned, long, short để phù hợp với mục đích lưu trữ và xử lý.

Việc chọn kiểu dữ liệu đúng không chỉ giúp bộ nhớ hợp lý mà còn tránh các lỗi tràn số, sai lệch dữ liệu, và gây nguy hiểm khi xử lý phép toán trên biến.

Điểm cốt lõi

  • ✓int dành cho số nguyên; float/double dành cho số thực.
  • ✓char được dùng cho ký tự và mã ASCII.
  • ✓scanf/printf là cách nhập/xuất chuẩn trong C.
Ví dụ input.c 
#include <stdio.h>

int main() {
    int a = 10;
    float b = 3.5f;
    printf("a = %d, b = %.2f\\n", a, b);
    return 0;
}
Học C Cấu trúc dữ liệu Lập trình hệ thống

Ngôn ngữ lập trình C/C++

C là một ngôn ngữ lập trình có cấu trúc, hiệu suất cao, và rất quan trọng trong các môn học kỹ thuật. Trong quá trình học, sinh viên cần nắm rõ từng khái niệm như kiểu dữ liệu, vòng lặp, điều kiện, hàm, mảng, con trỏ, cấu trúc và thao tác tệp.

Điểm đặc biệt của C là khả năng làm việc ở tầng thấp, cho phép lập trình điều khiển bộ nhớ, xử lý kernel, driver, và phần mềm nhúng. Tuy nhiên, chính vì vậy, người học cần thận trọng trong việc quản lý biến, con trỏ và vùng nhớ.

Ví dụ tổng hợp

Đoạn mã dưới đây minh họa cách sử dụng if, for và hàm trong C để tính tổng số chẵn từ 1 tới 10:

Ví dụ sum_even.c 
#include <stdio.h>

int sumEven(int n) {
    int total = 0;
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 0) {
            total += i;
        }
    }
    return total;
}

int main() {
    int x = 10;
    printf("Tong so chan tu 1 den %d la: %d\\n", x, sumEven(x));
    return 0;
}

Để học tốt C, bạn nên đọc bài từng chương, làm bài tập thực hành, và viết lại các ví dụ bằng tay để hiểu đúng bản chất của ngôn ngữ. Một lưu ý quan trọng là C rất nhạy với lỗi con trỏ và định dạng dữ liệu.
