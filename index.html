1.1 Khái niệm ngôn ngữ C
UTT p.12

Ngôn ngữ C là ngôn ngữ lập trình bậc trung, có tốc độ thực thi nhanh, khả năng kiểm soát bộ nhớ mạnh mẽ và được dùng nhiều trong hệ thống, phần mềm nhúng, và ứng dụng hiệu năng cao.

C là ngôn ngữ có cú pháp gọn, ít ẩn dụ hơn so với các ngôn ngữ hiện đại, nhưng lại cực kỳ mạnh vì cho phép lập trình ở mức thấp mà vẫn kiểm soát cấu trúc dữ liệu rõ ràng.

Điểm cốt lõi

  • ✓Ngôn ngữ C có tính cấu trúc, hướng thủ tục.
  • ✓Khả năng quản lý bộ nhớ trực tiếp bằng con trỏ.
  • ✓Phổ biến trong hệ thống, nhúng, driver, và engine game.
Ví dụ main.c 
#include <stdio.h>

int main() {
    printf("Xin chao C!");
    return 0;
}
2.1 Kiểu số nguyên và thực
UTT p.24

Trong C, các kiểu dữ liệu cơ bản bao gồm int, float, double, char, cùng với các kiểu unsigned, long, short để phù hợp với mục đích lưu trữ và xử lý.

Việc chọn kiểu dữ liệu đúng không chỉ giúp bộ nhớ hợp lý mà còn tránh các lỗi tràn số, sai lệch dữ liệu, và gây nguy hiểm khi xử lý phép toán trên biến.

Điểm cốt lõi

  • ✓int dành cho số nguyên; float/double dành cho số thực.
  • ✓char được dùng cho ký tự và mã ASCII.
  • ✓scanf/printf là cách nhập/xuất chuẩn trong C.
Ví dụ input.c 
#include <stdio.h>

int main() {
    int a = 10;
    float b = 3.5f;
    printf("a = %d, b = %.2f\\n", a, b);
    return 0;
}
3.1 if, else, switch
UTT p.47

Điều kiện là cơ sở để chương trình có thể rẽ nhánh theo trạng thái của biến, dữ liệu đầu vào hoặc điều kiện nghiệp vụ.

switch thường thích hợp với các trường hợp lựa chọn nhiều nhánh rõ ràng, còn if/else được dùng linh hoạt hơn trong các biểu thức logic phức tạp.

Điểm cốt lõi

  • ✓if/else xử lý điều kiện.
  • ✓switch xử lý nhiều nhánh rõ ràng.
  • ✓Không nên lồng quá sâu nếu không cần thiết.
Ví dụ branch.c 
#include <stdio.h>

int main() {
    int score = 70;
    if (score >= 80) {
        printf("Gioi\\n");
    } else if (score >= 60) {
        printf("Kha\\n");
    } else {
        printf("Yeu\\n");
    }
    return 0;
}

Ngôn ngữ lập trình C/C++

C là ngôn ngữ lập trình có tính cấu trúc, hiệu suất cao và rất quan trọng trong các môn kỹ thuật. Người học cần thành thạo lập trình tuần tự, điều kiện, vòng lặp, hàm, mảng, con trỏ và thao tác tệp.

Điểm đặc biệt của C là khả năng làm việc ở tầng thấp, cho phép điều khiển bộ nhớ và xây dựng các ứng dụng hệ thống, trình điều khiển và phần mềm nhúng. Vì vậy, cần chú ý đến định dạng biến, con trỏ, và logic rẽ nhánh.

Ví dụ tổng hợp

Đoạn mã dưới đây minh họa cách tính tổng số chẵn từ 1 tới n:

Ví dụ sum_even.c 
#include <stdio.h>

int sumEven(int n) {
    int total = 0;
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 0) {
            total += i;
        }
    }
    return total;
}

int main() {
    int x = 10;
    printf("Tong so chan tu 1 den %d la: %d\\n", x, sumEven(x));
    return 0;
}

Để học tốt C, nên đọc bài từng chương, viết lại ví dụ bằng tay và làm nhiều bài tập thực hành. Mỗi thao tác sẽ giúp bạn làm quen với cú pháp, tính đúng sai, và kỹ năng debug.

Thi thử lập trình C

Trong phần thi thử, bạn sẽ làm quen với dạng câu hỏi về kiểu dữ liệu, phạm vi biến, vòng lặp, mảng, con trỏ và tối ưu code. Mục tiêu là kiểm tra khả năng đọc hiểu logic và viết mã đúng trình tự.

Để đạt hiệu quả, hãy luyện tập từng phần nhỏ trước khi thi. Đặc biệt, bạn nên tập trung vào việc kiểm tra điều kiện rẽ nhánh, vòng lặp và cách sử dụng con trỏ đúng chuẩn.

Ví dụ câu hỏi

Hãy xác định đầu ra của đoạn code sau:

Câu hỏi Q1 
#include <stdio.h>

int main() {
    int x = 5;
    int y = 2;
    printf("%d\\n", x / y);
    return 0;
}

Tự luận lập trình C

Phần tự luận tập trung vào kỹ năng viết mã, giải quyết bài toán, và code theo logic rõ ràng. Bạn cần xây dựng chương trình từ đầu, xử lý đầu vào, đầu ra, kiểm tra điều kiện và chạy thử.

Học qua bài tự luận giúp bạn rèn tư duy thuật toán, kiểm soát lỗi, và cải thiện khả năng phân tích vấn đề theo hướng cấu trúc hơn.
